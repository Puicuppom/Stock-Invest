# ตั้งค่าซิงค์ ReBalance

ค่าเริ่มต้นบันทึกพอร์ตใน localStorage ของเบราว์เซอร์ หากต้องการใช้บริการซิงค์เดิม ให้คัดลอก .env.example เป็น .env.local และตั้งค่า:

| ตัวแปร | ค่า |
| --- | --- |
| REBALANCE_SUPABASE_URL | URL โปรเจกต์ Supabase |
| REBALANCE_SUPABASE_ANON_KEY | anon key สำหรับฝั่งเบราว์เซอร์ ห้ามใช้ service-role key |
| REBALANCE_SYNC_KEY | ชื่อชุดพอร์ตที่ต้องการซิงค์ |

รีสตาร์ตเซิร์ฟเวอร์หลังแก้ไฟล์ บนโฮสต์ให้ตั้ง Environment Variables ชื่อเดียวกัน

## รูปแบบบริการเดิม

ต้องมีตาราง portfolios ที่มี sync_key เป็นคีย์ unique, data เป็น JSON/JSONB และ updated_at เป็น timestamp รวมถึงสิทธิ์อ่าน/เขียนและ Realtime ตามการตั้งค่าของโปรเจกต์ Supabase เดิม โค้ดนี้ไม่ได้สร้างตารางหรือเปลี่ยนนโยบายฐานข้อมูลให้

ค่าทั้งสามถูกส่งให้เบราว์เซอร์ผ่าน /api/rebalance-config การย้ายมาไว้ใน env ช่วยไม่ให้ติดไปกับ repository แต่ไม่ได้ทำให้เป็นความลับจากผู้ใช้เว็บ

ระบบเดิมไม่มีล็อกอินและใช้ sync_key เดียวร่วมกัน ผู้ที่เข้าถึงเว็บไซต์จะได้รับคีย์เดียวกัน จึงไม่ควรใช้เก็บพอร์ตส่วนตัวบนเว็บไซต์สาธารณะโดยไม่มีระบบยืนยันตัวตนและนโยบาย RLS ที่จำกัดผู้ใช้ ถ้ายังไม่ได้ตั้งค่าการเข้าถึง ให้เว้นค่าทั้งสามว่างเพื่อใช้ localStorage

ในเครื่องนี้ค่าจากไฟล์ต้นฉบับถูกเก็บไว้ใน .env.local ซึ่ง Git จะไม่อัปโหลด หากนำโปรเจกต์ไปเครื่องอื่นต้องตั้งค่าใหม่
