# InvestPui

เว็บวิเคราะห์หุ้น SET/US และจัดสัดส่วนพอร์ตในโปรเจกต์เดียว สร้างด้วย Next.js, React และ TypeScript

## ฟังก์ชัน

- **วิเคราะห์หุ้น** (`/`): Watchlist, กราฟราคา, แนวรับ/แนวต้านแบบ Pivot และ Swing, ประเมิน Fair Value จากหลายโมเดล และแผนซื้อขาย
- **ปรับพอร์ต** (`/rebalance`): จัดกลุ่มสินทรัพย์ กำหนดสัดส่วนเป้าหมาย ติดตามกำไร และคำนวณปรับพอร์ต
- เก็บ Watchlist และพอร์ตใน localStorage โดยแยกข้อมูลกัน
- รองรับการซิงค์พอร์ตผ่าน Supabase ที่ตั้งค่าเพิ่มเติมได้

## เริ่มใช้งาน

ใช้ Node.js 22 LTS และ npm

```bash
npm ci
npm run dev
```

เปิด [localhost:3000](http://localhost:3000) ใช้งานแบบบันทึกในเครื่องได้ทันทีโดยไม่ต้องตั้งค่า Supabase

หากต้องการซิงค์ ให้คัดลอก `.env.example` เป็น `.env.local` แล้วกรอกค่าของคุณ ดู [การตั้งค่าซิงค์](docs/rebalance-sync.md)

## คำสั่ง

| คำสั่ง | การทำงาน |
| --- | --- |
| `npm run dev` | เปิดเซิร์ฟเวอร์พัฒนา |
| `npm run check` | ตรวจ ESLint, TypeScript และไวยากรณ์ JavaScript ของ ReBalance |
| `npm run build` | สร้าง production build |
| `npm start` | เปิด production build หลัง build สำเร็จ |

เซิร์ฟเวอร์ต้องเชื่อมต่อ Yahoo Finance ได้ และขั้นตอน build ต้องดาวน์โหลด Google Fonts ได้ หากพบ `fetch failed` ให้ตรวจเครือข่ายหรือข้อจำกัด sandbox ของเซิร์ฟเวอร์

## โครงสร้าง

```text
src/
  app/
    page.tsx                  หน้าวิเคราะห์หุ้น
    rebalance/page.tsx        หน้าปรับพอร์ต
    api/
      stock/route.ts          API ราคาเพื่อใช้ใน ReBalance
      stock/[symbol]/         API ข้อมูลหุ้นและกราฟ
      rebalance-config/       ส่งค่าซิงค์ที่เปิดเผยต่อเบราว์เซอร์
  components/                 ส่วนประกอบหน้าเว็บและเมนู
  hooks/                      การจัดการสถานะและ Watchlist
  lib/                        ดึงข้อมูลและคำนวณการวิเคราะห์
public/
  rebalance-app/
    index.html                โครงหน้า ReBalance
    styles.css                รูปแบบหน้า ReBalance
    app.js                    การคำนวณ จัดการพอร์ต และซิงค์
  icon.svg
  manifest.json
scripts/                      สคริปต์ช่วยเปรียบเทียบ Fair Value
docs/                        คู่มือ GitHub และการตั้งค่าซิงค์
.env.example                  ตัวอย่างการตั้งค่า ไม่มีค่าจริง
```

ReBalance เปิดภายใน iframe เพื่อแยก CSS และสคริปต์จากหน้าวิเคราะห์หุ้น โดยใช้ API ของ Next.js ตัวเดียวกัน ไม่ต้องใช้โฟลเดอร์ ReBalanceStock ต้นฉบับ

## นำขึ้น GitHub และ Deploy

ทำตาม [คู่มือ GitHub](docs/github.md) โปรเจกต์ต้องใช้โฮสต์ที่รัน Next.js ฝั่งเซิร์ฟเวอร์ได้ เช่น Vercel หรือ Node.js server เพราะมี API จึงใช้ GitHub Pages โดยตรงไม่ได้

เมื่อใช้ Vercel ให้ Import repository แล้วตั้ง Environment Variables หากต้องการซิงค์ จากนั้น Deploy โดยใช้ค่า Next.js ที่ระบบตรวจพบ

## ข้อมูลและข้อจำกัด

- หุ้นไทยใช้ตลาด BKK เช่น PTT; หุ้นสหรัฐใช้ US เช่น AAPL ชื่อซ้ำกันได้ จึงต้องเลือกตลาดให้ถูกต้อง
- ราคาอ้างอิงราคาปิดล่าสุดจาก Yahoo Finance อาจล่าช้า ไม่ใช่ราคาสดสำหรับส่งคำสั่งซื้อขาย
- Fair Value เป็นผลคำนวณของเครื่องมือ ไม่รับรองว่าตรงกับบริการภายนอก
- localStorage แยกตามเว็บไซต์/โดเมน ข้อมูลจากเว็บเดิมจึงไม่ย้ายเองเมื่อเปลี่ยนโดเมน
- ระบบซิงค์เดิมไม่มีล็อกอิน อ่านรายละเอียดก่อนเปิดใช้งานในเว็บไซต์สาธารณะ
- เครื่องมือนี้ใช้ประกอบการวิเคราะห์ ไม่ใช่คำแนะนำการลงทุน

## คัดหุ้น

เมนู `/screener` เลือกถือยาว ปันผล หรือเทรดสั้นได้ กดค้นหาจาก Yahoo Finance ตามตลาด กลุ่มธุรกิจ และขนาดบริษัท ครั้งละ 30 รายการ พร้อมค้นหาชุดถัดไป หรือเลือก Watchlist ของตลาด US/BKK สูงสุดครั้งละ 30 ตัว โดยไม่ต้องกรอกชื่อหุ้น และเพิ่มผลลัพธ์เข้า Watchlist ได้ ระบบเรียกข้อมูลพร้อมกันไม่เกิน 3 ตัวและแสดงผลที่โหลดล้มเหลวแยกต่างหาก

- ถือยาว: Forward EPS > 0, FCF Yield > 0%, Upside ถึง Fair Value ≥ 10%, โมเดลมูลค่า ≥ 2
- ปันผล: Dividend Yield 2–8%, ปันผลต่อหุ้น > 0, FCF Yield > 0%, trailing P/E > 0
- เทรดสั้น: ราคาปิดเหนือ SMA20, SMA20 เหนือ SMA50, volume ≥ 1.2 เท่าของค่าเฉลี่ย 20 วันก่อนหน้า, ราคาเหนือ Pivot

ผ่านครบหมายถึงผ่านทุกเงื่อนไขของชุดนั้นเท่านั้น ค่าที่ไม่มีข้อมูลไม่ถือว่าผ่าน ใช้กับหุ้นสามัญ ไม่ใช้คัด ETF/ทอง/ค่าเงิน เกณฑ์นี้เป็นตัวกรองเบื้องต้น ไม่ได้ตรวจคุณภาพกิจการย้อนหลังหลายปี ความต่อเนื่องของปันผล หรือสแกนหุ้นทั้งตลาด

การค้นหาใช้ `/api/discover` ติดต่อ Yahoo screener แทนรายชื่อคงที่ เรียง Market Cap มากไปน้อยตามตัวกรอง แสดงจำนวนก่อนกรองชนิดสินทรัพย์และจำนวนที่ตัดออกรายชุด รวมผลชุดถัดไปโดยไม่ซ้ำสัญลักษณ์

ผลคัดหุ้นแสดงราคาเข้าซื้ออ้างอิงตามแนวทาง: ถือยาวใช้ Fair Value จากอย่างน้อย 2 โมเดล × 80%, ปันผลใช้ปันผลต่อหุ้นรายปี ÷ 4% (ก่อนภาษี สมมติปันผลคงเดิม), เทรดสั้นใช้แนวรับ Pivot ใกล้สุดที่ไม่เกินราคาปิดและจุดตัดขาดทุนต่ำกว่า 1.5% สูตรเป็นสมมติฐานเริ่มต้น ไม่ใช่การรับรองคุณภาพหุ้นหรือราคาสำหรับส่งคำสั่งซื้อจริง

กราฟเริ่มต้นเป็น 1Y (แท่งรายวัน) โหลดประวัติเพิ่มก่อนช่วงแสดงเพื่อคำนวณ EMA20/50 และ SMA200 ให้ต่อเนื่องในช่วง 1Y/6M เมื่อมีประวัติพอ พร้อมแสดงค่าล่าสุดของเส้น หุ้นเข้าใหม่อาจยังมีประวัติไม่ครบ 200 แท่ง

แถบเล็กเหนือกราฟแสดงต่ำสุด/สูงสุดจาก High/Low ของแท่งเทียนใน timeframe ที่เลือก โดยใช้ช่วงเดียวกับแท่งที่แสดง ไม่รวมประวัติเพิ่มสำหรับคำนวณ EMA และไม่โหลดการ์ดประวัติทั้งหมดแยกอีก

## รูปแบบหน้าจอ

ทั้งสามหน้าใช้สีและตัวอักษรร่วมจาก `public/design-system.css` หน้าปรับพอร์ตโหลดไฟล์เดียวกันใน iframe เพื่อให้ธีม ปุ่ม ช่องกรอก และสถานะตรงกับหน้าวิเคราะห์และคัดหุ้น เมนูหลักใช้ตำแหน่งและขนาดเดียวกัน รองรับ focus สำหรับคีย์บอร์ด

ตัวกรองขนาดบริษัท: US ใหญ่ ≥ 10B USD / กลาง 2–<10B / เล็ก <2B; ไทย ใหญ่ ≥100B THB / กลาง 10–<100B / เล็ก <10B เป็นนิยามของแอป กลุ่มธุรกิจใช้หมวด Yahoo ตัด DR/วอร์แรนต์ไทยตามชื่อที่ผู้ให้บริการระบุ API ผู้ให้บริการอาจเปลี่ยนหรือจำกัดการเรียก หากผิดพลาดแสดงข้อความแทนการใช้รายชื่อเดิมเงียบ ๆ

การค้นหาจะโหลดรายชื่อต่อเนื่องจนได้หุ้นที่ผ่านทุกเงื่อนไขเพิ่ม 30 ตัวต่อชุด หรือหมดขอบเขตข้อมูล แสดงเฉพาะที่ผ่านครบเป็นค่าเริ่มต้น ดูจำนวนตรวจและโหลดไม่ได้ได้ตลอด หยุดแล้วค้นหาต่อได้โดยเก็บคิวที่ยังไม่ตรวจไว้ เปลี่ยนแนวทางหรือตัวกรองจะเริ่มชุดใหม่

ผลคัดหุ้นแสดงเฉพาะหุ้นที่ผ่านครบและจัดอันดับตามคะแนน 0–100 ของแต่ละแนวทาง ดูน้ำหนักและสูตรได้ในหน้าคัดหุ้น คะแนนเปรียบเทียบเฉพาะผลที่โหลดแล้ว ไม่ใช่อันดับทั้งตลาด และไม่ใช่ความน่าจะเป็นในการทำกำไร
